## Estudo (08/11/2026)
**O que o vídeo ensina ou mostra**
1. Instalar o repositório **google-maps-scraper-kit** (grátis, ~2 mil estrelas, Python).
2. Ligar o robô com um comando no Docker (`docker compose up`) e abrir a pasta no Claude Code.
3. Pedir: "lista as clínicas de estética de Campinas". Ele busca no Google Maps, entra no site de cada empresa e caça o e-mail.
4. Recebe planilha com nome, telefone, e-mail, site, endereço e nota (~120 empresas por busca; para a cidade inteira, dividir o mapa em pedaços).
5. Conferir antes de ligar (empresa existe? telefone bate?) e apagar dado ruim.
6. Não exagerar: muitas buscas seguidas e o Google trava o acesso.
7. Com o repositório **Evolution API**, pedir ao Claude para chamar as empresas no WhatsApp uma a uma, com motivo real em cada mensagem; disparo em massa pode bloquear o WhatsApp.

**Ferramentas citadas**
- google-maps-scraper-kit (dono do repositório parcialmente legível; "Python · MIT" na tela), Docker, Evolution API (`evolution-api`), Claude Code.

**Grátis ou pago / local**
- Grátis, local (Docker).

**Aplicação para a agência**
- Prospecção de clientes locais no Recife: útil, mas com cuidado. Raspar o Google Maps vai contra os termos do Google; Evolution API não é a API oficial do WhatsApp (risco de banimento). Docker pesa em 8 GB. Usar com volume baixo e abordagem individual, como o próprio vídeo recomenda; ou preferir a busca manual e a Kapso (oficial) para mensagens.
