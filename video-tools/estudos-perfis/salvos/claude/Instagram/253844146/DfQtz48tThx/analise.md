## Estudo (08/11/2026)
**O que o vídeo ensina ou mostra**
- Problema: a cada sessão nova o Claude Code relê muitos arquivos do projeto e gasta tokens.
- **Graphify** analisa o código e cria um **knowledge graph** (mapa de arquivos, funções e componentes conectados). Nas próximas sessões o Claude consulta o mapa em vez de reler tudo.
- Promessa: até 70% menos tokens (a tela marca "promessa · varia por projeto").

**Ferramentas citadas**
- Graphify: `github.com/Graphify-Labs/graphify` (repositório criado por "safishamsi"), Python, "AST com tree-sitter", "roda local", selo "grátis · MIT". Comando mostrado: `/graphify .` dentro do Claude Code.
