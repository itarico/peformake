# CEO PORTFÓLIO DE FRENTES

O maior risco do Italo não é falta de ideia, é dispersão. Aqui ele é o conselho
de administração das próprias empresas.

## 1. Matriz do portfólio (atualize a cada trimestre)

Para cada frente, preencha (peça os números que não estiverem no banco):

| Frente | Receita/mês | Margem | Horas do Italo/semana | Crescimento 90d | Papel |
|---|---|---|---|---|---|
| Ellcazo | | | | | Vaca leiteira? |
| Peformake | | | | | Motor de crescimento? |
| Gastromake | | | | | Aposta (opção real) |
| Shopee | | | | | Caixa tático / teste |
| Marca pessoal | | | | | Ativo de distribuição |
| RaizFrame | 0 | — | 0 | — | Pausado |

Métrica-rainha: **R$ de lucro (ou de valor construído) por hora do Italo.**

## 2. Classificação (BCG adaptado)

- **Vaca leiteira** (receita estável, pouco tempo do dono): proteger, sistematizar,
  não inventar. Ellcazo tende a estar aqui — o audiovisual é ~2/3 do MRR do sistema.
- **Estrela** (cresce e exige investimento): onde vai a maior parte do tempo novo.
- **Aposta/opção** (sem receita, alto potencial): orçamento fixo de horas e marco
  de corte com data. Ex.: Gastromake — "primeiro restaurante pagante até [data]
  ou pausa".
- **Abacaxi** (consome tempo, não devolve): pausar ou fechar.

## 3. Regras de alocação

1. **70/20/10** do tempo do Italo: 70% na frente que paga as contas e cresce, 20%
   na estrela seguinte, 10% em apostas. Shopee e RaizFrame não podem passar de 10%.
2. Nenhuma frente nova sem: (a) uma frente pausada/cortada, (b) teste de 20% com
   prazo de 4 semanas, (c) critério de corte escrito antes de começar.
3. **Sinergias reais** valem mais que frentes novas: Gastromake é a ponte natural
   do nicho de gastronomia da Peformake (base de restaurantes existente =
   primeiros usuários e cases). Marca pessoal é o canal de aquisição da Peformake.
4. Sociedades: regra escrita de divisão de resultado, papel e saída para cada
   frente com sócio (Ellcazo, Peformake). Sem isso, conflito é questão de tempo.

## 4. Decisão de nova oportunidade (checklist)

- Tem cliente/dinheiro real esperando? Quanto em 90 dias?
- Usa um ativo que já existe (base de clientes, equipe, audiência, sistema)?
- Qual frente perde horas para isso, e quanto isso custa em R$?
- Versão de 20% testável em 4 semanas? Critério de sucesso e de corte?
- Recomendação final: SIM / NÃO / TESTE — com o porquê.

## 5. Patrimônio

Separar CPF e CNPJ; pró-labore definido por frente; reserva de 6 meses pessoal
e 3 meses por empresa antes de apostas. Não assuma valores — peça os atuais.
