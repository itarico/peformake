# JOGOS VORAZES — IDENTIDADE VISUAL
## Pacote de produção: ARQUIVOS DE PANEM

Este pacote reúne o conceito visual e materiais iniciais para orientar a edição de um documentário cinematográfico sobre toda a franquia Jogos Vorazes.

### Conteúdo
- `01_Manual`: identidade visual, paleta, tipografia e regras.
- `02_Guia_de_Edicao`: linguagem de montagem, motion graphics, transições e som.
- `03_Assets_Editaveis/SVG`: cartela, lower third, cartão de arquivo e mapa esquemático editáveis.
- `04_Referencias`: termos de pesquisa para montar o moodboard.
- `05_Templates`: instruções de uso dos arquivos vetoriais.

### Como começar
1. Leia o manual de identidade.
2. Abra os SVGs no seu editor preferido.
3. Monte um moodboard usando as consultas do arquivo de referências.
4. Aplique a evolução estética: origem → sistema → jogos → revolução.

### Nota sobre imagens
O pacote não incorpora imagens oficiais dos filmes nem fotografias de referência encontradas na internet. As referências foram organizadas como consultas de pesquisa; os SVGs são assets gráficos originais e editáveis.

### Direitos
Jogos Vorazes e seus elementos protegidos pertencem aos respectivos titulares. Este pacote é um guia independente de direção de arte e não é oficial nem afiliado à franquia.
