# 📝 TEMPLATE DE PROMPT PARAMETRIZÁVEL

## Variáveis a Substituir

```

[NICHO] → Segmento/mercado
[CIDADE/ESTADO] → Localização
[SITE] → URL
[INSTAGRAM] → @instagram
[SERVIÇOS] → Lista de serviços
[TOM_VOZ] → Forma de comunicação
```

```
## REGRAS DE QUALIDADE

1. ✅ Reels SEM SOM — sempre legenda nos 3 primeiros segundos
2. ✅ Gancho DIRETO — nunca comece com "Olá"
3. ✅ Dados REAIS — cite números concretos
4. ✅ Tom REGIONAL — mencione [CIDADE/ESTADO]
5. ✅ 1 OBJETIVO por conteúdo — não misture temas
6. ✅ Priorize [PÚBLICO_ALVO] — 60% do conteúdo
7. ✅ Cite DATA — "trend de junho 2026"
8. ✅ Formato 9:16 — vertical para Reels/Stories
9. ✅ Verifique CONCORRENTES — busque realmente
10. ✅ DIY PRÁTICO — ideias que [PÚBLICO_ALVO] consegue fazer
```
