MDD — MOLDE DE ALTA RETENÇÃO: "CICATRIZ → PROVA → VOLTA"

Camada de Aplicação Italo (@italosantosdigital)

Status: REFERÊNCIA OPCIONAL — NÃO É REGRA

===========================================

REGRA FIXA (inegociável)

===========================================

Todo roteiro roda SEMPRE o pipeline completo (Passos 1–7) e é validado pelos 5 filtros no fim.

A estrutura do roteiro é CONSEQUÊNCIA das etapas — nunca uma fôrma aplicada por cima.

Este molde NÃO é rota obrigatória. É só mais uma carta no baralho, puxada quando o assunto pedir.

===========================================

QUANDO CONSIDERAR ESTE MOLDE

===========================================

• Território: Pensamento & Ensino.

• Existe vivência real do Italo pra ancorar o assunto (Story-Mining disponível).

• O assunto é um princípio/tese que ganha força com prova.

Se não houver cicatriz pra ancorar, OU o assunto pedir humor puro / POV seco / soap opera em Stories / outro formato → o pipeline leva pra lá. Não forçar este molde.

===========================================

ANATOMIA DO MOLDE (7 batidas)

===========================================

1. PORTA = vivência real (Story-Mining). Abre com autoridade + identificação. Ninguém copia porque é do Italo.

2. TESE NASCE DA HISTÓRIA. O princípio cai da cena, não é colado de fora.

3. PROVA DUPLA E BEM EXPLICADA. Uma histórica + uma científica/dado. Explicar direito é inegociável — é o que vira opinião em fato. (A prova é o que sustenta; a cicatriz é o que faz chegar até ela.)

4. SÍNTESE EM REGRA DE 3. Amarra as fontes numa frase ("o sargento, o imperador e o cientista disseram o mesmo").

5. GUARDRAIL EM 1 FRASE. Protege o inimigo declarado (ex.: "parecer ≠ fingir"). Impede que a tese vire fachada/coach.

6. DESFECHO = CALLBACK À PORTA. Volta pra cena inicial → sensação de vídeo redondo.

7. FORMA: ≤60s, uma ideia por frase, costura MAS/ENTÃO (nunca "e aí"). Venda invisível.
