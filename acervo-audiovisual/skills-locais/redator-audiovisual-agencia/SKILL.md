## 🎭 ESTILOS NARRATIVOS COMPLETOS

### NARRATIVAS CLÁSSICAS

**3 Atos**
```
Ato 1 (25%): contexto, personagem, problema
Ato 2 (50%): tentativas, obstáculos, virada
Ato 3 (25%): solução, transformação, lição
```
Melhor para: YouTube, cases, depoimentos, brand films

**Jornada do Herói**
```
Mundo comum → Chamado → Recusa → Mentor
→ Travessia → Provações → Recompensa → Retorno → Transformação
```
Melhor para: narrativas de marca, lançamentos, histórias de transformação

**Story Circle — Dan Harmon**
```
1. Conforto → 2. Querer algo → 3. Desconforto → 4. Adaptação
→ 5. Conquista → 6. Preço pago → 7. Retorno → 8. Mudança permanente
```
Melhor para: séries de conteúdo, narrativas em episódios

**In Medias Res**
```
Início: cena de clímax ou tensão máxima
Meio: contexto e desenvolvimento
Fim: resolução e lição
```
Melhor para: Reels, TikToks — prender nos primeiros 3s

**Narrativa em Loop**
```
Final = começo: provoca rewatch automático
→ Algoritmo lê como retenção alta
→ Espectador assiste múltiplas vezes sem perceber
```
Melhor para: TikTok viral, Reels de alto alcance

**Kishotenketsu — Narrativa sem conflito (japonesa)**
```
Ki: introdução do contexto
Sho: desenvolvimento natural
Ten: virada completamente inesperada (twist)
Ketsu: reconciliação/nova perspectiva
```
Melhor para: conteúdo de curiosidade, educativo com twist, surpreender

**Pirâmide Invertida**
```
Topo: informação mais importante primeiro
Meio: contexto e desenvolvimento
Base: detalhes e complementos
```
Melhor para: carrosséis, LinkedIn, conteúdo educativo

### 🔀 NARRATIVAS HÍBRIDAS — A Especialidade da Agência

Estas são estruturas únicas que misturam estilos para criar conteúdo imprevisível e de alta retenção.

**Híbrido 1: Cotidiano → Quebra → Propaganda**
```
[0-8s] Cena cotidiana realista entre personagens
       (conversa, situação engraçada, momento normal)
[8-15s] Quebra de padrão: algo inesperado acontece
        (reação exagerada, corte abrupto, virada de roteiro)
[15-30s] Revelação da marca/produto de forma natural
         (produto aparece como solução ou parte da cena)
```
Exemplo: duas pessoas reclamam de algo → uma resolve com o produto → CTA

**Híbrido 2: Documentário → Testemunho → Oferta**
```
[0-10s] Câmera documental, tom sério e investigativo
[10-20s] Pessoa real compartilhando resultado verdadeiro
[20-30s] Revelação da solução + oferta com urgência
```
Exemplo: "Investigamos por que pessoas X conseguem Y" → cliente conta → "o método é esse"

**Híbrido 3: Ficção → Realidade → Produto**
```
[0-15s] Cena claramente ficcionada, estilo novela ou cinema
[15-20s] Quebra do 4º muro: personagem olha para câmera
[20-30s] Fala direta para o espectador sobre o produto
```

**Híbrido 4: Notícia Falsa → Correção → Marca**
```
[0-5s] Manchete ou breaking news falso (declaradamente)
[5-20s] "Correção" que é o conteúdo real
[20-30s] Conexão com a marca de forma orgânica
```

**Híbrido 5: Comédia → Educação → Conversão**
```
[0-10s] Situação engraçada e identificável da persona
[10-20s] Informação real e valiosa sobre o tema
[20-30s] CTA suave conectado à solução
```

**Híbrido 6: Mini-Filme → Manifesto → CTA**
```
[0-45s] Narrativa emocional completa com personagem
[45-55s] Declaração de valores da marca (manifesto)
[55-60s] CTA que se conecta emocionalmente com o filme
```

**Híbrido 7: Trend + Conteúdo Próprio**
```
[0-5s] Aderir ao trend viral do momento (som, formato, gestual)
[5-25s] Conteúdo original e relevante para o nicho
[25-30s] CTA natural que sai do trend
```

**Híbrido 8: Série Episódica com Cliffhanger**
```
Episódio 1: apresenta personagem + problema + cliffhanger
Episódio 2: desenvolvimento + nova virada + cliffhanger
Episódio 3: resolução + produto como herói + CTA
→ Cada episódio funciona sozinho mas cria desejo pelo próximo
```

### 🎨 ESTILOS VISUAIS E CINEMATOGRÁFICOS

**UGC (User Generated Content)**
```
Câmera na mão, levemente tremida, ambiente real
Tom informal, como se filmado por acidente
Alta autenticidade = alta confiança = maior conversão
Ideal para: anúncios frios, produtos físicos, serviços locais
```

**Talking Head + B-Roll**
```
Narrador falando direto para câmera (talking head)
Intercalado com imagens de apoio (b-roll)
Estrutura: fala 3s → b-roll 2s → fala 3s → b-roll 2s
Ideal para: educativo, autoridade, YouTube
```

**Mockumentary**
```
Estilo documentário mas com situações criadas
Entrevistas "espontâneas" roteirizadas
Humor sutil ou drama exagerado
Ideal para: humanização de marca, bastidores fictícios
```

**Found Footage**
```
"Filmado por acidente" ou "câmera que estava ligada"
Grão de vídeo, timestamp, qualidade propositalmente ruim
Cria sensação de realidade bruta
Ideal para: lançamentos surpresa, revelações, bastidores
```

**Slice of Life**
```
Cena cotidiana hiper-realista sem roteiro aparente
Personagem não olha para câmera
Produto/serviço aparece naturalmente na cena
Ideal para: produtos de uso diário, lifestyle
```

**Day in the Life**
```
Acompanhar uma rotina completa (real ou fictícia)
Produto/serviço integrado naturalmente
Tom pessoal e íntimo
Ideal para: humanização, infoprodutos, coaching
```

**Manifesto**
```
Declaração de valores e propósito da marca
Edição rápida, música épica, copy inspiracional
Sem venda direta — vende a ideia
Ideal para: branding, lançamento de marca, campanhas
```

**Mini-Filme (60-90s)**
```
Narrativa completa com início, meio e fim
Personagens, conflito e resolução reais
Marca aparece como solução, não interrupção
Ideal para: campanhas sazonais, lançamentos, datas especiais
```

## 🧬 NEUROMARKETING — Ciência por Trás do Conteúdo

### Os 6 Gatilhos Neurais Principais

**Dopamina — Antecipação e Recompensa**
```
Como ativar: abrir loops sem fechar, prometer antes de entregar,
             revelar informação aos poucos, cliffhangers
Como usar: "No final desse vídeo você vai descobrir..."
           "Fica até o final para o maior erro de todos"
Efeito: espectador não consegue parar de assistir
```

**Oxitocina — Confiança e Conexão**
```
Como ativar: vulnerabilidade real, histórias pessoais,
             mostrar rostos humanos, tom empático
Como usar: bastidores reais, erros assumidos, conquistas compartilhadas
Efeito: espectador sente que conhece e confia na marca
```

**Cortisol — Urgência e Atenção**
```
Como ativar: ameaça, problema não resolvido, prazo, escassez
Como usar: "Você está perdendo dinheiro enquanto lê isso"
           "Isso vai parar de funcionar em breve"
Efeito: espectador age por medo de perder ou ficar pra trás
⚠️ Usar com moderação — excesso cria fadiga e desconfiança
```

**Neurônios Espelho — O Espectador Sente o que Vê**
```
Como ativar: emoções genuínas na tela, expressões faciais reais,
             situações que o espectador já viveu
Como usar: mostrar alívio real, conquista real, frustração real
Efeito: espectador sente as emoções como se fossem suas
```

**Ancoragem — Primeiro Número Define Tudo**
```
Como ativar: mostrar valor alto antes do valor real,
             comparar com alternativa mais cara
Como usar: "Invisto R$5.000 por mês em tráfego.
            Com essa estratégia orgânica, faço o mesmo de graça."
Efeito: percepção de valor muito maior que o preço real
```

**Viés de Perda — Perder Dói 2x Mais que Ganhar**
```
Como ativar: mostrar o que o espectador está PERDENDO agora,
             não o que vai ganhar
Como usar: "Cada dia sem fazer isso você perde X clientes"
           "Enquanto você hesita, seu concorrente está crescendo"
Efeito: motivação para agir muito maior que promessa de ganho
```

## 🎯 PERSUASÃO AVANÇADA

### Cialdini — 6 Princípios Aplicados ao Vídeo

```
Reciprocidade: entregar valor real ANTES de pedir algo
→ Aplicar: dar o melhor conteúdo gratuito possível no vídeo

Compromisso: pequenas concordâncias que levam à grande
→ Aplicar: "Se você concorda com X, então Y faz sentido pra você"

Prova Social: outros iguais a mim já fizeram
→ Aplicar: depoimentos, números, cases de pessoas parecidas com a persona

Autoridade: especialista reconhecido indica
→ Aplicar: credenciais, resultados, certificações, anos de experiência

Escassez: poucos disponíveis, tempo limitado
→ Aplicar: vagas, prazo, edição limitada (só usar quando verdade)

Afinidade: gosto de quem é parecido comigo
→ Aplicar: espelhar linguagem, valores e estilo de vida da persona
```

### Monroe's Motivated Sequence — Sequência para Ação
```
1. ATENÇÃO: hook que interrompe o scroll
2. NECESSIDADE: mostrar o problema que o espectador tem
3. SATISFAÇÃO: apresentar a solução
4. VISUALIZAÇÃO: mostrar como será depois da solução
5. AÇÃO: CTA claro e específico
```
Melhor para: vídeos de venda, anúncios, lançamentos

### Pattern Interrupt — Quebra de Padrão
```
O cérebro ignora o que é previsível
→ Fazer algo inesperado nos primeiros 3 segundos
→ Exemplos: som estranho, corte abrupto, frase chocante,
            mudança repentina de cena, pergunta provocadora
→ Resultado: atenção total e involuntária
```

### Loop Aberto — Tensão Narrativa
```
Abrir uma pergunta e não responder imediatamente
→ "Vou te contar o que aconteceu, mas antes..."
→ "O motivo vai te surpreender... deixa eu te explicar"
→ Cérebro precisa fechar loops abertos = assiste até o fim
```

### Contraste — Antes/Depois Emocional
```
Mostrar a situação ruim de forma vívida antes da solução
→ Quanto mais real a dor, mais satisfatória a solução
→ Usar linguagem sensorial: "imagina acordar todo dia com..."
```

### Método Socrático — Perguntas que Levam à Conclusão
```
Fazer perguntas que a persona responde "sim" internamente
→ "Você já perdeu um cliente para o concorrente este mês?"
→ "Você sente que seu Instagram não traz resultado?"
→ "Você sabe que precisa mudar mas não sabe por onde?"
→ Após 3 "sins" mentais, a pessoa está pronta para ouvir a solução
```

## 📢 ANÚNCIOS PAGOS — Estruturas de Criativos

> Todo conteúdo criado deve ter DUAS versões: **orgânica** e **anúncio**.

### Estruturas de Meta Ads (Facebook/Instagram)

**Criativo UGC de Conversão**
```
[0-3s] Hook visual que para o scroll no feed (sem logo, sem branding)
[3-15s] Problema narrado de forma natural, câmera na mão
[15-25s] Descoberta da solução (produto/serviço)
[25-30s] Resultado + CTA direto
Tom: pessoa comum falando para amigo, não para câmera publicitária
```

**Criativo de Testemunho**
```
[0-3s] Frase mais impactante do depoimento (no começo, não no fim)
[3-20s] História completa da transformação
[20-28s] Detalhe específico do resultado (número, tempo, situação)
[28-30s] CTA
```

**Criativo Educacional com Oferta**
```
[0-5s] Promessa de valor: "3 formas de X que ninguém te conta"
[5-25s] Entregar 2 formas reais de valor
[25-28s] "A terceira — e mais poderosa — está em..."
[28-30s] CTA para a oferta
```

**Criativo Problema-Amplificação-Solução**
```
[0-3s] Cena visual do problema (sem fala)
[3-10s] Narração amplificando as consequências
[10-20s] Solução apresentada com prova
[20-30s] CTA com urgência ou benefício
```

**Criativo de Comparação**
```
[0-5s] "Antes de conhecer X, eu fazia assim..." (jeito errado)
[5-20s] "Depois que descobri X, tudo mudou" (jeito certo)
[20-30s] CTA para experimentar
```

**Criativo de Objeção**
```
[0-5s] Nomear a objeção principal da persona diretamente
[5-20s] Refutar com prova, dado ou lógica
[20-30s] CTA com garantia ou facilidade
```

### Variações A/B Obrigatórias para Todo Anúncio
```
Variação A: hook de curiosidade
Variação B: hook de dor/problema
Variação C: hook de prova social
→ Criar as 3 versões de hook para o mesmo criativo
→ Texto primário: versão curta (2 linhas) + versão longa (problema-solução)
→ CTA: 2 versões (benefício vs. urgência)
```

## 🛍️ CONTEÚDO POR TIPO DE NEGÓCIO DO CLIENTE

### Se o cliente tem PRODUTO FÍSICO
```
Formatos que mais convertem:
→ Demonstração em uso real (slice of life)
→ Unboxing com reação genuína
→ "Por que eu comprei" (perspectiva do consumidor)
→ Antes/depois visual do produto
→ Tutorial de como usar com resultado

Neuromarketing aplicado:
→ Mostrar textura, cor, peso (neurônios espelho)
→ Pessoas reais usando (prova social visual)
→ Close no detalhe que justifica o preço (ancoragem)
```

### Se o cliente tem SERVIÇO
```
Formatos que mais convertem:
→ Bastidores do processo de entrega
→ "Um dia na vida" do profissional
→ Resultado antes/depois do cliente
→ Resposta a dúvidas frequentes em vídeo
→ Case de sucesso em formato mini-documentário

Neuromarketing aplicado:
→ Mostrar o processo (reduz ansiedade da compra invisível)
→ Rosto humano sempre (oxitocina)
→ Resultados específicos com números (credibilidade)
```

### Se o cliente tem INFOPRODUTO / CURSO
```
Formatos que mais convertem:
→ Mini-aula gratuita (reciprocidade)
→ Transformação possível visualizada
→ Objeção principal refutada em vídeo
→ Aluno compartilhando resultado
→ "Por que eu não aprendi isso antes"

Neuromarketing aplicado:
→ Mostrar a vida depois do curso (dopamina/visualização)
→ Loop aberto: dar valor, criar desejo pelo resto
→ Viés de perda: "cada mês sem isso você atrasa X"
```

### Se o cliente tem NEGÓCIO LOCAL
```
Formatos que mais convertem:
→ Vídeo do ambiente real (confiança)
→ Equipe apresentada por nome
→ Bastidores da operação
→ Cliente real dando depoimento no local
→ "O que tem aqui que você não encontra em outro lugar"

Neuromarketing aplicado:
→ Familiaridade gera confiança (ver o local reduz barreira)
→ Prova social local (avaliações, frequência de clientes)
→ Ancoragem de valor vs. concorrentes
```

## 📱 FORMATOS POR CANAL

### TikTok
```
Duração: 15-30s (viral) / 60-90s (educativo)
Hook: primeiros 1-3s decidem tudo
Estrutura: Hook → Desenvolvimento rápido → Twist/CTA
Trend sounds: usar quando relevante
Retenção > alcance: manter até o fim é mais importante
Top formatos: POV, tutorial rápido, polêmica, "ninguém fala sobre isso"
```

### Instagram Reels
```
Duração: 7-15s (viralização) / 30-60s (educativo) / 90s (profundo)
Primeiros 3s: hook visual + texto na tela
Capa do Reel: define clique no perfil — tratar como thumbnail
Música: trend ou energia certa para o conteúdo
```

### YouTube
```
Duração ideal: 8-15 minutos
Estrutura: Hook (0-30s) → Promessa → Desenvolvimento → Entrega → CTA
Thumbnail: rosto + expressão + texto 3-5 palavras + cor contrastante
Cards e telas finais: indispensáveis para reter
```

### YouTube Shorts
```
Duração: até 60s | Vertical 9:16
Loop: ideal terminar onde começou
Hook: primeiros 2s decisivos
```

### Stories
```
Sequência: 5-7 stories com narrativa progressiva
Story 1: hook forte
Stories 2-5: desenvolvimento com enquetes/perguntas
Story final: CTA claro
```

### Carrossel
```
Slide 1: hook visual — para o scroll em 2 segundos
Slides 2-8: um ponto por slide, desenvolvimento
Slide 9: resumo ou insight
Slide 10: CTA
```

## 🎣 BANCO DE HOOKS

**Curiosidade:** "O que ninguém te conta sobre [nicho]..." / "O erro silencioso que está sabotando seu [resultado]"
**Contradição:** "Pare de [ação comum] se quiser [resultado]" / "Fiz o oposto do que todos falam e funcionou"
**Identificação:** "Se você é [persona], isso é pra você" / "Você vai se ver nesse vídeo"
**Prova social:** "Fiz [ação] por [tempo] e [resultado concreto]" / "[Número] pessoas já fizeram isso"
**Urgência:** "Isso vai desaparecer do algoritmo em breve" / "Aproveita enquanto ainda funciona"
**Polêmica:** "Opinião impopular: [afirmação divisora]" / "Vou falar o que ninguém tem coragem de dizer"
**Neuro-hook:** "Seu cérebro vai resistir a isso, mas lê até o fim" / "Você não vai acreditar que estava fazendo errado"

## 📣 BIBLIOTECA DE CTAs POR OBJETIVO

> Nunca usar CTA genérico. Cada peça de conteúdo tem um objetivo e um CTA específico.

### CTAs por Objetivo

**🎯 OBJETIVO: Aumentar Seguidores**
```
→ "Segue aqui pra não perder o próximo"
→ "Ativa o sino — o próximo vídeo é ainda melhor"
→ "Me segue, que semana que vem tem a parte 2"
→ "Se isso foi útil, imagina o que posto todo [dia da semana]"
```

**💬 OBJETIVO: Gerar Comentários**
```
→ "Comenta aqui [palavra/emoji] se você já passou por isso"
→ "Me conta nos comentários: qual é o seu maior desafio com [tema]?"
→ "Concorda? Discorda? Me fala nos comentários"
→ "Comenta a letra [X] se quer que eu faça um vídeo sobre [tema]"
→ "Qual dessas situações você já viveu? Comenta o número"
```

**💾 OBJETIVO: Gerar Salvamentos**
```
→ "Salva esse vídeo — você vai precisar disso"
→ "Guarda aqui para não esquecer depois"
→ "Esse é o tipo de coisa que você vai querer rever"
→ "Salva e manda para quem precisa ver isso"
```

**📤 OBJETIVO: Gerar Compartilhamentos**
```
→ "Manda pra um amigo que precisa ouvir isso"
→ "Marca aqui quem você conhece que faz isso"
→ "Compartilha com alguém que está passando por isso"
→ "Quantas pessoas você conhece que precisam ver esse vídeo?"
```

**📩 OBJETIVO: Gerar DMs / Mensagens**
```
→ "Me manda uma DM com a palavra [X] e eu te envio [material gratuito]"
→ "Quer saber mais? Me chama no direct"
→ "Manda 'quero' no direct que te conto tudo"
→ "Envia uma mensagem com [palavra] para receber [benefício]"
```

**🔗 OBJETIVO: Gerar Cliques no Link**
```
→ "Link na bio pra você começar agora"
→ "Acessa o link na bio — tem algo te esperando lá"
→ "Entra no link da bio antes que [urgência real]"
→ "O próximo passo está no link da bio"
```

**💰 OBJETIVO: Gerar Vendas Diretas**
```
→ "Últimas vagas — link na bio"
→ "Abre hoje, fecha [data] — não perde"
→ "Clica no link, leva 2 minutos e muda tudo"
→ "Enquanto você está pensando, [X] pessoas já entraram"
```

**📞 OBJETIVO: Gerar Contato / Lead**
```
→ "Chama no WhatsApp — link na bio"
→ "Quer uma análise gratuita? Me manda mensagem"
→ "Preenche o formulário no link — respondo hoje"
→ "Me chama, vamos conversar sem compromisso"
```

**🔁 OBJETIVO: Aumentar Retenção / Rewatch**
```
→ "Assiste de novo — você vai perceber o que perdeu"
→ "Tem um detalhe escondido nesse vídeo — achou?"
→ "A parte mais importante está no começo e no fim"
```

### Regras de Uso dos CTAs

```
✅ Máximo 1 CTA por vídeo — dois CTAs = nenhum resultado
✅ CTA no final do vídeo E na legenda
✅ CTA deve ser específico: "comenta a letra A" > "comenta aí"
✅ CTA de venda só após 3+ conteúdos de valor na semana
✅ Variar CTAs — não repetir o mesmo por mais de 3 posts seguidos
✅ Adaptar CTA para cada canal (DM no Insta ≠ comentário no YouTube)
```
