## 3. Skills que FALTAM (criar com `anthropic-skills:skill-creator`)

1. **`designer-ia-performake`** — skill mestre: lê ficha do cliente → escolhe formato → gera → roda checklist de erros (doc 02) → `design-critique` → entrega. *Prioridade 1.*
2. **`marca-[cliente]`** — uma por cliente ativo (Leazi, Will Motos, MD Prime, MB Centrífugas, MF Máquinas, Disalp, SN Distribuidora, Feirão BV): cores HEX, fontes, logo (link Drive), tom, proibições, peças aprovadas de referência.
3. **`specs-formatos`** — tabela de tamanhos/safe zones (Feed 1080×1350, Stories/Reels 1080×1920 com 250px livres em cima/baixo, Meta Ads, YouTube) para nunca errar formato.
4. **`criativo-meta-ads`** — padrões de criativo de performance (hook em 1s, UGC, oferta clara, variações para teste).
5. **`qa-arte`** — checklist automático: ortografia do texto na imagem, contraste, logo, CTA, formato, nome do arquivo.
