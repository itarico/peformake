# Guia rápido: comandos no grupo da Peformake

Escreva **uma coisa por mensagem**. O sistema responde com o que entendeu: responda **ok** para confirmar ou **cancela** para desistir. Nada vai para cliente por aqui.

> Os comandos abaixo são o plano. Cada um só funciona quando o Italo ligar em Configurações, Automações.

## Agenda

- `agendar captação Transpetro sexta 14h`
- `agendar captação Padaria Bom Pão dia 15 9h30, local Boa Viagem, com Vinícius`
- `agendar reunião Studio Lu amanhã 10h`
- `remarcar captação Transpetro para segunda 9h`
- `cancelar captação Transpetro` (ou `desmarcar Studio Lu`)
- `agenda hoje` · `agenda sexta` · `agenda minha`

## Clientes

- `cadastrar cliente Padaria Bom Pão, tel 81 99999-0000`
- `cadastrar cliente Studio Lu 81999990000 ellcazo`
- `status Transpetro` (resumo, sem valores)
- `contato Transpetro`
- `nota Transpetro: pediu mais fotos de produto`

## Vendas e pagamentos

- `venda Padaria Bom Pão gestão de tráfego 1500 mensal`
- `venda Studio Lu reels 4 vídeos 2.400 avulso`
- `pagou Padaria Bom Pão 1500` (só sugere a baixa; um administrador confirma)

## Tarefas e leads

- `tarefa Transpetro: enviar roteiro para Vinícius até quinta`
- `lead Maria Souza 81 98888-1111 gestão de tráfego`

## Gastos (Financeiro, como já é hoje)

- `gasto 89,90 canva` · `gasto 250 combustível transpetro ontem` · `entrada 1200 padaria`

## Regras de ouro

- **Hora:** 14h, 14:30, 14h30. **Dia:** hoje, amanhã, sexta, dia 15, 15/11.
- **Cliente:** nome ou apelido (TP, Petro). Se houver dúvida, o sistema pergunta.
- **Venda** vai para "A confirmar". **Pagou** só sugere. Nada é cobrado nem enviado ao cliente.
- **Errou?** Responda à mensagem do sistema: `ok`, `cancela`, `remarcar segunda 9h`, `corrige 230`.
- **Não entendeu?** Digite `ajuda` ou `ajuda venda`. Cada pessoa só vê os comandos que pode usar.
